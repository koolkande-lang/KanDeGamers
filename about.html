HOW WE BUILD THINGS

  • One file per game. Each game is a single web page. Nothing to install, nothing to update, nothing that stops working next year.
  • Nothing gets downloaded. Every picture and every sound is made by the code as the game runs — there isn't a single image or audio file in the whole site. That's why it loads instantly, even on school wifi.
  • Playing together doesn't need a server. When you play online your devices talk straight to each other. No accounts, no logins, and nothing about you is stored anywhere.
  • It has to work on the thing you own. Phone, tablet or computer. Touch controls and keyboard controls both, every time — and it fits your screen without scrolling.
  • It gets tested before anyone plays it. There are 22 sets of automatic tests that run the games and check them. If something breaks, the tests say so before you ever see it.

WHY THE TESTS MATTER

It's not showing off — it's because we kept finding real problems. A few the tests caught before anybody played:

In Hush, the notes were handed out by a piece of maths that could give you the same note twice — and never show you the door code. The game would have been impossible to finish.

Also in Hush: the first version of the new graphics ran at about 7 frames a second. Unplayable. It's about eleven times faster now.

In Wuzzle, the word list turned out to come from a dictionary written in 1934. It didn't know yay, okay, taco or email. It knows them now.

And some things only a real person finds. Hush used to freeze completely when you finished watching a video tape — that one got reported by a player, not by a test. So a new set of tests was written specifically to hunt for it happening again.

WHAT'S NEXT

More games, and more to do in the ones that already exist. If you play something and it breaks, feels unfair, or just isn't fun — that's the most useful thing you can tell us.
